# MCB PDV System releases

Public release artifacts for **MCB PDV System**, a desktop point-of-sale (POS) built with Rust and iced.

- Linux x86_64 AppImage binaries
- `latest.json` update manifest consumed by installed clients

The source code stays in a private repository. Assets are published by the tag-triggered release workflow.

To update an existing installation, close the application, replace the current AppImage with the downloaded file and start it again. Back up the database before changing versions.
